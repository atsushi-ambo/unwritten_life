# スマホ向けの非公開OpenAI接続

現状は実装・検証用。公開中のスマホ体験版は静的版のままで、まだこのバックエンドへ移行していません。Sitesの指定するOpenAI Developersプラグインのキー設定手順が未完了です。キーをGit、HTML、チャット、ローカル設定ファイルへ書かないでください。

## 設計

- 既存のowner-private Siteを維持。Sitesのサーバー側 `getChatGPTUser()` で本人を確認し、匿名APIは401。同意、同一Origin、JSON、HttpOnly/Secure/SameSite=StrictのCSRF Cookieとヘッダーを必須にします。将来公開する場合には、別途対象利用者と課金の認可設計が必要です。
- `OPENAI_API_KEY` はSitesの秘密情報、`UNWRITTEN_ORIGIN` は対象Siteの正確なOrigin。ブラウザからキー・接続先・単価・上限を変更するAPIは提供しません。
- 手動生成のみ。固定のOpenAI Chat Completions、GPT-6 Luna、Standard、推論なし、出力上限1500token、90秒、返答128KB。ツール・Web検索・自動再試行・購入・チャージは行いません。
- D1の累計見積り上限$0.10、100回まで。小さい方で停止。入力のUTF-8バイト数+1024と最大出力を、2026-10-17の公式単価の2倍で予約します。これは提供者の請求額・残高を直接制御する上限ではありません。価格は導入時に再確認してください。
- 予約・同時実行ロック・リクエストIDを1トランザクションで保存し、再送と多重実行を拒否します。障害・中断・不正な返答も返金せず、再起動や再読み込みでリセットしません。中断時のロックは2分で失効します。
- D1に保存するのは累計予約額・回数・ロック、ランダムなリクエストID・開始時刻・状態のみ。キー、プロフィール、勤務先、生成文章は保存・ログ出力しません。リクエスト記録は最大100件。セーブは利用者のブラウザにのみ保存します。
- AIに渡す情報は既存の `storyRequest`、返答の行動・長さ検証と数値表現の補正もPC版と共有します。成否や年収・資産はゲーム側で計算します。

## ソースの用意と検証

SitesスキルのVinextスターターを**別の空ディレクトリ**に用意します。メインリポジトリの依存を `npm ci --ignore-scripts` で用意した上で、以下を実行します。

```sh
node scripts/prepare-hosted.mjs /absolute/path/to/vinext-checkout
npm run check
npm run audit
```

`prepare-hosted` は公開用8ファイル、APIラッパー、共有バックエンド、Drizzleスキーマと生成済みマイグレーション、更新した依存定義とロックをコピーします。その後、出力先でSitesの依存インストール手順を実行してください。このフォルダのpackage.jsonは、その出力先用の依存スナップショットです。ここで直接サーバーを起動するものではありません。

既存のSites ID、公開範囲、接続情報は変更しません。スターターのトップページだけは、ゲームの移植後に除去します。新規のD1スキーマは `npm run db:generate` で生成し、適用済みのSQLとメタデータは変更しないでください。

ホスティングの設定は既存のproject_idを維持し、`static` を取り除き、`d1: "DB"`、`r2: null` にします。Sitesのビルド手順、ローカルD1マイグレーション適用、型検査、依存検査を済ませてから、指定のキー設定手順と非公開配備へ進みます。スターターのローカル認証モックは本番認証の証明には使いません。

`test/hosted.test.js` は生成されたSQLを実際のSQLiteへ適用し、正常な生成、認証・CSRF・同意・入力の拒否、上限の境界、再送、並列要求、中断後の累計保持、不正なAI返答と自動再試行なしを検証します。外部AI通信は合成データのテスト実装で、実課金しません。

元の静的版と新しいWorkerのソース・ビルドを別々に保持してから、既存Siteのソースへ移植します。D1を削除・初期化して戻す手順にはしません。失敗時は元の静的版を同じprivate Siteへ戻せますが、ブラウザのセーブは別途書き出しで保全してください。

## 依存検査の残り

2026-10-17の準備版は、Next 16.4.2、Vinext 1.2.1、React 19.3.1、Vite 8.3.4、Cloudflare Viteプラグイン1.64.0、Wrangler 4.151.1へ更新してビルドしています。ロックした本番依存の `npm audit --omit=dev --audit-level=high` は0件です。CIは同じ本番依存検査を実行し、Dependabotはこのロックも週次確認します。

開発依存を含めた全検査は合格ではなく、8 High・7 Moderateの警告が残ります。Highは修正版のない [bracesの再帰によるDoS](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) と開発用の依存チェーンです。今回のAPIはプロフィールやAIの文章をglobパターンとして渡さず、固定のファイルパスだけをビルドします。Worker出力のソースマップにもbraces・micromatch・fast-globは含まれていません。ModerateはDrizzleの開発用esbuildと、未使用のOG画像処理系のfflateの依存チェーンです。スキャン全体は無効化していません。

この評価は今回の固定ソースに限定します。2026-10-24まで、または配備・ビルド入力・画像生成機能の変更前の早い方で再確認し、未信頼のファイル・パターン・画像をこれらの開発ツールへ入力しないでください。全依存検査の成功や安全性の保証とは扱いません。
