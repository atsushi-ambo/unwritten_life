# AIの接続と費用

確認日：2026-10-17。サービスの料金・利用可能モデル・制限は変更されます。

## 選び方

最初の体験はPC内のOllama + qwen3:8b。約5.2GBのモデルを取得した後、APIの従量課金なしで生成できます。通信・電力・機器の費用がなくなる意味ではありません。ローカルモデルの日本語やJSONの品質、速度は機種とモデルに依存します。

M5・メモリ32GBでこのゲームを遊ぶ場合は、今回の比較では `gemma4:12b-it-q4_K_M`（約8GB）を推奨します。取得後は同じモデル一覧から選べます。[測定条件・結果・プロンプトの比較](local-models.md) を参照してください。既存のOpenAI等の設定は、この比較スクリプトからは変更しません。

- [Ollamaのモデル情報](https://ollama.com/library/qwen3:8b)
- [OllamaのChat API](https://docs.ollama.com/api/chat)
- [ローカル専用モードとGPUの確認](https://docs.ollama.com/faq)
- [LM Studioの互換API](https://lmstudio.ai/docs/developer/openai-compat)

より強い生成が必要なら、利用者自身でクラウド接続を選べます。ゲーム内の「AIに渡す情報」で、年齢、仕事、現在の資産・住まい、前提として確認した会社の公開情報、直近4年の選択を確認できます。性別・APIキーは物語のプロンプトに含めません。

## APIの費用例

1場面あたり入力4,000・出力1,000トークン、60場面、通常の短いコンテキスト料金、キャッシュ割引なしという**計算例**です。実測ではありません。入力・日本語の長さ・モデルの推論トークン・再生成・税・決済手数料等で変わります。

| 例                 | 入力100万token | 出力100万token |  60場面の例 |
| ------------------ | -------------: | -------------: | ----------: |
| PC内のOllama       |    API課金なし |    API課金なし | API課金なし |
| OpenAI gpt-6-luna  |          $0.10 |          $0.50 |      $0.054 |
| OpenAI gpt-6.1-sol |          $2.00 |         $10.00 |       $1.08 |

計算式：`場面数 × (入力token × 入力単価 + 出力token × 出力単価) / 1,000,000`。[OpenAI公式料金](https://developers.openai.com/api/docs/pricing)のStandard短コンテキストの例を使用。利用権・残高・提供条件は各アカウントで確認します。現在の画面の単価は利用者が変更できます。

OpenRouterは選んだモデルの単価で変わります。公式料金ページではStandardのクレジット購入手数料は5.5%、無料モデルには回数制限があり、基本は毎分20回・1日50回、所定の購入条件を満たすと1日上限が増えると案内されています。無料枠の可用性や継続を保証しません。無料モデルを使う場合もAPIキーが必要です。[OpenRouter公式料金](https://openrouter.ai/pricing)

会社情報のURL取得は通常のHTTP取得で、有料AI検索を使いません。検索ボタンは会社名だけをGoogleへ渡し、利用者のブラウザで公式サイトを探します。毎年Web検索を行う設計ではありません。

## アプリ内の上限

以下はPC版の上限です。スマホ用バックエンドの準備版は、別途[D1へ累計を保持する設計](../hosted/README.md)です。こちらはまだ配備していません。

- 自動呼び出しはしない。利用者が「この場面をAIで生成」を押す。
- 同じプロフィール・世界・seed・選択列は、この起動中のサーバーキャッシュを再利用する。セーブされた場面も再生成せず表示する。
- 生成は同時に1件。失敗しても自動リトライしない。
- 1回の出力は最大1500token。Ollamaは推論出力をオフ、コンテキスト8192token。
- 起動中の回数は初期値100回。失敗したリクエストも数える。ただしローカルのOllama・LM Studioへの接続拒否で送信できなかった場合だけ、回数と予約費用を戻す。タイムアウト・HTTPエラーは戻さない。
- クラウドは利用者の設定単価で、入力UTF-8バイト数+余裕と最大出力から費用を予約見積りする。次の予約が上限を超える場合は呼ばない。
- 設定変更で回数・費用をリセットしない。再起動ではリセットする。
- 生成中の設定変更は受け付けず、設定変更後は前の設定の生成キャッシュを使わない。

ローカルAIへの接続拒否では起動方法を案内します。生成が120秒でタイムアウトした場合は小さいモデルや時間をおいた再試行を案内し、ゲームの条件に合わない出力はAIの提案を採用しなかったと表示します。

これは提供者の請求口座に対する強制上限ではありません。モデル単価の設定違い、サービスの手数料・特別料金等はアプリから保証できません。必要なら提供者側の予算・利用制限も設定します。

## ChatGPT / OpenCode / 他のAI

「好きなAIと手動で交換」で、現在の状態を含む依頼文をコピーし、任意のAIに渡せます。返答はJSONを貼り付けて取り込み、アプリが検証します。アプリから勝手にChatGPTやOpenCodeを操作したり、保存済みの認証情報を取り出したりしません。

[OpenCodeのサーバーAPI](https://docs.opencode.ai/docs/server/)はOpenAI互換APIと同一ではありません。現在の対応は手動交換です。[Sign in with ChatGPTのOSS向け公式資料](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)も存在しますが、現在の版ではOAuth・プラン利用の登録フローを実装していません。将来の追加候補として分離します。

## 開発用の接続口

`public/story.js` は語り手の指示と最小限のコンテキストを構築し、`lib/ai.mjs` が接続・上限・出力検証を行います。`POST /api/scene` はv2のセーブ文字列を受け取り、その状態を再計算してから場面を生成します。外部AIは場面のタイトル、本文、洞察、既存の行動IDの選択肢だけを返せます。任意のコード、ツール呼び出し、数値報酬、未知の行動IDは受け付けません。

ローカルHTTP APIは `GET /api/status` の一時トークン、同一Origin、JSON Content-Typeを要求します。ブラウザの外の開発ツールが使う場合も、明示的にこのトークンとOriginを付けます。これはPC上の他のプロセスから情報を守る認証基盤ではありません。OSの利用者自身が信頼境界です。

## 毎年の自動生成とモデル選択

Ollama・LM Studioはダウンロード済みモデルを一覧取得して選択する。前の選択が一覧にあれば維持し、なければ取得済みの `gemma4:12b-it-q4_K_M` を優先する。それもなければ一覧の先頭を選ぶ。Ollamaは公式の [`GET /api/tags`](https://docs.ollama.com/api/tags)、LM Studioは固定ローカルURLの `/v1/models` を使い、設定保存時にも一覧内のモデルか確認する。モデルのダウンロードは行わない。Ollamaのcloudタグ・remote情報のある項目は一覧に含めない。

ローカルAIでは開始時と選択後に毎年1回生成する。初期オンのチェックで停止できる。回数上限・出力上限・キャッシュは自動生成にも適用し、失敗は自動再試行しない。クラウド接続時には自動生成しない。人物の条件を変えると処理時間も変わるが、ローカルモデルの推論にAPI課金はない。

[Ollamaの構造化出力](https://docs.ollama.com/capabilities/structured-outputs)で現在可能な行動を指定し、同じ固定の文章を繰り返さず直前の結果に続く場面と選択肢を生成する。成否と金額はゲーム計算で確定し、LLMの文章だけで残高を変更しない。

## 残高とカード請求の確認

このアプリにAPIのクレジット残高を読み取る機能や、クレジット購入・自動チャージの処理はありません。OpenAI等のAPI利用は提供者側の課金対象です。「残高分だけ使う」運用では、利用者本人のAPI請求画面で残高・有効期限・請求プラン・支払い方法・自動チャージの状態を確認してください。ChatGPTの契約・支払い設定とは分けて確認します。

アプリの見積り上限と回数制限は、この起動中の呼び出しを止めるための補助です。サーバー再起動でリセットされ、APIアカウントの請求を強制的に止める上限ではありません。OpenAI側ではアラートと強制上限も別の設定で、強制上限にも反映の遅れがあると説明されています。[OpenAI公式・Spend limits](https://developers.openai.com/api/docs/guides/spend-limits)。

OpenAIの初期候補GPT-6 Lunaでは `reasoning_effort: "none"` を指定し、1500トークンの出力枠を場面JSONに使います。他のモデルへ同じ設定を一律に送信しません。[モデル公式仕様](https://developers.openai.com/api/docs/models/gpt-6-luna)。クラウドは手動生成・毎回の送信同意とし、失敗時の自動再試行や追加購入への切り替えは行いません。
