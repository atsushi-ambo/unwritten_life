# 生涯モデル v0.2

## 目的と権限

2026年の自分から、入力と選択で変わる生涯を遊ぶ。アプリは家計・状態・時間の進行を、LLMは入力や履歴に合う架空の場面と選択肢を担当する。AIの追加を予測精度の保証として扱わない。

利用者は自分のブラウザのプロフィール、選択、生成場面の保存・削除を行える。公開投稿・他人のデータへのアクセス・ログイン・決済はない。ローカルサーバーのみで動かし、APIキーは起動中のメモリに限定する。外部AIや取得ページにPCの操作権限は与えない。

## 入力と状態

基本8項目：年齢18〜100、国内3地域、8職種、税引き前年収、AI利用経験、価値観、金融資産合計、持ち家/賃貸等。任意で株式内訳、不動産評価額、住宅ローンと金利・期間、生活費、家賃、世帯、退職年齢、65歳以降の収入、会社タイプ・名前・公開資料を設定する。

金融資産合計から株式を引いたものを現金とする。初期金融資産が負なら、負の額をその他借入として扱う。純資産は `現金 + 株式 + 不動産 − 住宅ローン − その他借入`。住居の評価額は別枠。ローンは評価額と独立で、売却価格を借入から逆算しない。

性別は表示・計算・LLMプロンプトに使用しない。年齢は時間、退職、生活費、加齢、終了確率に反映する。会社名単独から業績や給与を予測しない。

## 年ごとの計算

金額は万円、2026年の購買力の仮定。税引き前年収の76%を使えるお金として、生活費×12、家賃またはローン元利返済・不動産維持費、行動費用、高齢期の追加費用を差し引く。76%は実際の税計算ではない。家賃と持ち家費用は二重に引かない。

株式の年変化率は2.5%±17%、不動産は±3%のseed付き乱数。不動産維持費は評価額の年1%。配当・銘柄・税制・売買税・相続は再現しない。住宅ローンは月次元利均等の式を使い、12か月の利息・元金を順に計算する。固定金利とし、繰上返済はモデル化しない。

現金不足なら株式を必要額だけ売却する。それでも不足する分は、借入と仮定して不足を累計し、年2%の利息を加算する。現実に融資が承認されることを意味しない。破産・公的支援・生活保護はモデル化していない。

給与は基礎成長・年次変動・スキルによるAIの補完利益・移行負担・仕事への集中・ゆとり不足から変化する。通常変化率は±12%内。転職では移行費用と追加の収入変化を適用する。退職年齢または退職行動で給与を0とし、65歳から入力した年金等を加算する。実際の受給条件・制度を再現した年金推計ではない。

## 入力と選択による分岐

転職は給与・スキル・関係・自由と以後の職場の場面を変える。以後は初期勤務先の資料を現職の事実として使わない。資産配分は現金から株式へ振り替える。住居購入は地域別の仮の価格を使い、頭金20%・諸費用5%・借入80%とする。賃貸の地域変更では地域の生活費比率に応じ支出を変える。退職では給与が止まる。

AIの普及速度は3シナリオ。勤務先タイプからの導入係数と、利用者が確認した会社の事業分類を仕事の曝露係数に最大20%混ぜる。これらは会社の実測データに較正した推計ではない。初期勤務先の公開情報はAIの場面にも渡すが、出典のない将来の発表や解雇計画を事実として作らないよう指示する。

ルール側の場面も退職、資金不足、転職、AI普及、直近の選択、世帯と住まいに応じて変化する。AIは現在の状態と直近4年の履歴から、具体的な場面・3〜5の選択肢を作る。行動IDはその状態で実行可能なものに限定し、ラベル・文章の型と長さ、重複を検証する。数値を直接指定させない。画面に行動の意味も併記し、生成ラベルと実際の処理を判断できるようにする。

## 最期までの進行

年ごとに、年齢・ゆとり・技術のシナリオから独自の終了確率を計算する。`0.0005 × exp(max(年齢−35,0)/10) × (1+(50−ゆとり)/180) / (1+AI普及×0.08)` を0.0002〜0.6に制限。110歳で必ず終了する。これは公開生命表に較正しておらず、個人の寿命予測ではない。死因は作らない。終わりの年齢は開始前に表示しない。

1年または5/10年の同じ重点で進行する。複数年進行でAIは自動呼び出ししない。途中で終了や行動条件の不成立になればそこで止まる。巻き戻しでは同じseedから再計算し、後続の選択と場面を破棄する。

別世界比較は初期条件・seed・選んだ行動を固定し、AIの普及速度を変える。別世界で先に終了した場合や、資金条件を満たさず行動できなくなった場合はその年までの結果を表示する。同じ行動を実行できた年だけで比較し、未実行の将来を勝手に補わない。生成文章は比較時に再生成せず、課金もしない。

## 信頼境界と通信

HTTPは127.0.0.1にbind。Hostをlocalhost/127.0.0.1に限定し、静的ファイルは許可リスト。APIのPOSTは同一Origin、JSON、一時CSRFトークンを要求し、1MB・毎分60件まで。CORS許可を追加しない。CSPはブラウザの通信を同一オリジンに限定する。

会社ページはHTTPS・公開IPのみ。IPv4/IPv6の内部・予約アドレス、認証付きURL、非標準ポートを拒否する。DNSの全候補を検証し、接続先IPを固定して再解決によるすり替えを防ぐ。転送は2回まで、都度再検証。1ページ512KB、名前解決5秒、リクエスト15秒。HTMLはparse5でテキスト化し、実行しない。外部コンテンツは命令として解釈しない。

AI接続は利用者が設定したループバックまたはHTTPSの公開先だけ。リダイレクトは追跡しない。本文128KB・120秒、同時1件。APIキーをURL・ログ・保存・返答に含めない。プロンプトにツール・シェル権限を渡さない。費用と回数は [ai-and-costs.md](ai-and-costs.md) に記載する。

## 保存・検証・公開

セーブv2はプロフィール・世界・seed・選択・生成場面。最大250,000文字、選択と場面は110件まで。復元時は再検証・再計算する。旧v1は保持して書き出しを可能にし、黙って再計算しない。

`npm run check`をローカル・CIで共用し、合成データと一時ローカルHTTPのみで検証する。有料APIはCIで呼ばない。依存はnpm lockfile、外部ActionsはSHA固定、Dependabotと週次・手動のauditを維持する。GitHub上の検査成功と、実機のOllama確認・ブラウザ確認は別に記録する。

現在は非公開リポジトリのローカルアプリ。将来のOSS公開ではライセンスの確定、秘密情報と個人データの再確認、インストール手順、外部AIやモデルの利用条件を確認する。個人情報を含む公開の投稿機能やランキングは要件に追加しない。
