# ゲーム中の語り

入口の「まだ知らない、自分のつづきへ。」と同じ温度で、選んだ行動が日々にどう残り、次に何を迷うのかを描く。見出しのコピー自体を繰り返さない。

- 場面はその人の仕事や暮らしに合う小さな出来事から始め、短い常体で描く。報告書、自己啓発、過剰な詩にしない。
- 本文の最後は、次の選択につながる迷いを残す。本人が書いていない感情や願いを断定しない。
- 4択は行動が分かる方針名にする。負担・不確実さ・プロフィールとの接点も、短く自然な言葉で伝える。
- 努力が報われない年、減収や損失も記録どおり描く。感動の押しつけや成功の予告で埋めない。重い出来事を軽く言い換えない。
- 数値や結果はそのまま確認できる。語りのために確率・収入・家族・企業の事実を変えない。

AI向けの指示は `public/story.js` の `SCENE_STYLE` にまとめ、ローカル・CLI・API・スマホ版の場面生成と企業比較で共通に使う。指示の重複を整理し、今回の変更前より短くした。スキーマ、生成上限、自動再試行は変更しない。

年表の汎用見出し7件は `public/app.js` の表示時だけ言い換える。たとえば「毎日の学びが、仕事に生きる場面へ。」を「学んできたことに、出番が来た。」とする。保存済みの履歴や生成文章は書き換えず、詳しい記録も維持する。新しいAI文体は更新後に新しく生成する場面から適用するため、既存サーバーの再起動が必要。
