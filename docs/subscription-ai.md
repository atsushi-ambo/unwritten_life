# PC版のサブスクCLI連携

> 2026-10-19追記：このゲームはAIの接続を必須にしました。毎年の場面・4択・転職候補はすべて接続したAIが本人の入力から作り、ルールで用意した選択肢と手動のJSON交換は使いません。新しい候補に固定の企業リストは使わず、旧セーブの再現用データだけを残します。接続先（ローカル・サブスクCLI・API）はどれでも毎年自動で生成し、クラウドは接続時の送信同意が必要です。一度提示・在籍した企業はセーブの `careerSeen` と `pastCandidates` でAIに渡し、繰り返さないよう指示します。過去の生成例・測定結果は記載当時の記録です。 接続方式を選び、短いJSONの生成を確認してから開始します。サブスクは契約の利用枠まで使い、暴走防止の上限だけ初期1000回・最大5000回とします。


確認日：2026-10-18。PC版の「AIの接続設定」でCodex CLIまたはClaude Codeを選べます。利用者本人が事前に公式CLIでサブスクのアカウントにログインしてください。アプリはトークンファイルを読み出したりコピーしたりせず、公式CLIを標準入力で呼び出します。スマホ版にはこの接続を公開しません。

## 接続と上限

- Claude Codeは `haiku`・`sonnet`・`opus`（初期値 `sonnet`）。Codexは `gpt-6.1-sol`（初期値）、`gpt-6-astra`、`gpt-6-sol`、`gpt-6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`。2026-10-19にローカルCLIの `--help`・`exec --help`・設定を確認し、モデル一覧用の独立コマンドは見つからなかったため、`models_cache.json` の表示対象モデルを採用しました。契約ごとの利用可否は接続時に確認します。ブラウザから任意のモデルは指定できません。APIキー認証を拒否し、外部APIのキー・接続先・CLI設定先を指定する環境変数を子プロセスへ引き継ぎません。シェル経由では起動しません。
- 接続時の送信同意後に毎年自動生成します。契約の利用枠（5時間枠など）を使い、暴走防止にサーバー起動中は初期値1000回・最大5000回（設定で変更できます）、同時1件、1回120秒、入力128KB、標準出力と標準エラーの合計128KBまで。失敗も1回と数え、同じ場面の成功結果はキャッシュします。上限はサーバー再起動で戻ります。契約の上限をCLIが返した場合は専用の案内で止まり、自動再試行しません。
- 独立した一時ディレクトリで実行し、終了時に削除します。ツール・MCP・フック・ブラウザ・スキル等を無効にし、Codexは読み取り専用サンドボックスも指定します。文章以外の操作を含む返答を拒否し、既存のJSON・行動・数値表現の検証を通します。ゲームの計算や選択肢の規則は変えません。
- アプリは失敗時の再呼び出し、有料APIへの接続、別モデルへの自動変更を行いません。公式CLI自身の通信処理はCLIに依存します。Claudeは最大1ターン（出力上限での打ち切りをCLIが続けた場合の最大3ターンまで受け付けます。ツールは無効）・思考を含めた出力8192token（接続確認は1024token）、CLI側の1回の見積り予算上限はHaiku `$0.05`・Sonnet `$0.30`・Opus `$1.00` を指定しています。予算の判定はCLI側の見積りであり、1回の応答で超える場合があります。
- サブスクの上限や残量をアプリは取得しません。追加利用・クレジット・自動購入が契約側で有効だと、サブスク枠を超えた利用が課金される可能性があります。**各社の設定で追加利用と自動購入を無効にして使ってください。アプリだけで請求額ゼロを保証するものではありません。**

接続時と再読み込み時は、ログイン確認に加えて `{"ok":true}` を生成・検証します。確認は90秒、返答は短く制限し、ゲームの回数には含めません。ローカルは120秒、APIの確認はUSD見積りを予約します。生成を確認できた日時をサーバー状態に保持し、失敗時は開始できません。

## 検証

`npm run check` はCLIをインストールしていないCIでも実行できます。認証方式の拒否、資格情報の引き継ぎ防止、固定引数、一時領域の削除、実プロセスの時間・容量制限、完了した文章以外の拒否、同意前・回数超過時の呼び出しゼロ、キャッシュ、失敗時の再試行なしをテストします。

2026-10-18の旧設定では、このPCで架空プロフィールから場面と4択の生成・取り込みまで確認しました。Codex CLI `0.163.0-alpha.10.2` はChatGPTログインで約15秒、Claude Code `2.1.302` はProログインで約12秒。Claudeは当初の出力1500tokenでは思考で上限を使い切ったため、4096tokenへ調整し、最大1ターンを明示しました。実サービスでの確認はテストのモックとは分けて記録しています。2026-10-19の変更後の実CLI生成・各モデルの利用可否は未確認です。

2026-10-20：Claude Code `2.1.304`（Pro）でHaikuを選ぶと場面の生成が「Claude Codeの生成が完了しませんでした」で止まる不具合を修正しました。Haiku 5.5は `MAX_THINKING_TOKENS=0` でも1場面に約2,500〜3,700tokenを思考に使い、4096tokenの上限を超えると、CLIが2ターン目で返答を完成させます。正常な返答なのに1ターン以外を拒否していたのが原因です。出力上限を8192tokenに上げ、ツール無効のまま最大3ターンを受け付け、失敗時は理由（予算超過・ターン数など）を表示します。修正後、架空プロフィールの実CLI生成でHaiku（人生3回・転職1回、各17〜20秒）とSonnet（人生・転職、各8〜9秒）がすべて1ターンで成功しました。テストから実CLI生成や有料APIは呼びません。

## 調査結果

| 候補 | 利用枠と実行方法 | このゲームへの方針 |
| --- | --- | --- |
| OpenAI / Codex | ローカル・OSSアプリ向けにSign in with ChatGPTでプランの利用枠を使う公式経路がある。Codex app-serverとも接続できる。 | 最優先候補。新規の接続はアプリ自身のSign in with ChatGPTを優先し、既存CLI認証をアプリから読み出す方式にはしない。 |
| Anthropic / Claude Code | 現在は公式の `claude -p`、Agent SDK、第三者アプリでもサブスク枠を使えると案内されている。Max・Teamでは月次APIクレジットの選択肢もある。 | 公式CLIまたは公式SDKの経路を用いる。APIキー経由とサブスクのログインを区別する。 |
| Google / Gemini CLI | 個人のGoogleログイン、Google AI Pro/Ultraの枠に対応。ログイン済みの認証は非対話実行でも使われる。 | 追加候補。CLIへの事前ログインを必要とし、APIキー・Vertex経由の従量課金と分ける。 |
| OpenCode | CLIそのものは独立した無料の推論サービスではなく、選ぶプロバイダーや契約に依存する。公式資料にはChatGPT等の接続がある。Claude Pro/MaxのOAuth流用プラグインとは区別が必要。 | まず各社の公式接続を優先する。OpenCode経由のClaudeサブスク流用は採用しない。 |

OpenAIのapp-server資料は、既存のローカル・OSS用途での認証利用を説明する一方、商用・リモートホストのサービスとの違いを明示している。将来公開サイトをホストして全員を一人の契約で動かす方式へ、そのまま転用しない。利用者がそれぞれPCで実行し、自分のアカウントを接続する想定とする。

## 共通の接続方針

- 接続方式をOllama、API、サブスク連携として選択できる形にする。CLIがPC内で動いても、推論データは各社のクラウドへ送られるため、送信先とプロフィール・家計・会社・履歴の確認を表示する。
- サブスク枠は普段の作業と共有する。無制限・永久無料とは表示しない。1年につき1回を基本に、キャッシュ・回数制限・キャンセルを共通化する。上限に達したら停止し、利用者がOllama等への変更を選べるようにする。
- 有料API、追加クレジット、別モデルへ自動で切り替えない。APIキー等の環境変数で、意図せず別課金の認証が選ばれない設計にする。
- CLIのログインは利用者が公式の画面・CLIで行う。既存の認証ファイルやトークンをゲーム側へコピーしない。ブラウザから任意の実行ファイル・コマンド・追加引数を渡せないようにする。
- 入力はシェル展開せず標準入力へ渡す。ゲーム用の独立した作業領域を用い、ファイル・シェル・MCP・フック等の権限を文章生成に不要な限り無効にする。JSONの形と許可された行動を検証し、時間・出力・同時実行数を制限する。
- CLI側のバージョン、ログイン方式、対象モデルで実際に検証する。コマンドが見つかることと、サブスク認証での生成成功を区別する。
