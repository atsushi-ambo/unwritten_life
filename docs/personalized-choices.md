# 本人の文脈から作る4択

確認日：2026-10-17。AIの新しい生成は通常イベント・転職比較とも4択です。会社の例や職種別の固定リストをAIの候補の上限にはしません。

## 入力から提案へ

同じエンジニアでも、自社サービスの開発、受託/SIの顧客案件、事業会社の社内ITでは経験が異なります。規模・職種とは別に、任意の「仕事の形」を追加しました。未指定でも始められます。AIへは現在の勤務先と役割、確認した事業資料、本人の職歴メモ、仕事の形、家計、住居、家族と希望、直近の選択・結果、世界の局面を渡します。不明な背景を確定した経験として補わないように指示します。

通常イベントは、可能な行動全体からその年の4案を生成します。学習・家族・住居・起業・休養等も、本人との接点と負担を具体化します。子育て中は家族の具体的な時間や負担に向き合う案も含める指示です。選択肢のカテゴリを毎回同じ4種類に固定するものではありません。

転職比較は3つの企業案と残留案です。現在分かっている仕事の形に近い企業も含め、別の事業で経験を使う案や意外な接点もAIに考えさせます。自社サービスから別の自社サービス、SIから別のSIも可能です。同じ会社を重ねず、2036年より前に未来の架空企業を作る返答、明らかな仮名・部署名だけの実在候補は拒否します。AI未生成時には、従来の候補を「ルールで用意した候補」と明記して表示します。

## 表現と実行

各案はラベル、本人との接点 `reason`、負担や不確実さ `hint`、実行する `decision` を持ちます。通常の行動でも「自社サービスの信頼性を学ぶ」など具体的な `intent` を保存し、次の物語へ渡します。転職は企業名・役割・仕事の形・架空の職務提案、起業は事業IDと名前、地域変更は移転先を検証して実行します。具体案は1年ずつ進めます。

AIが挙げた企業名の実在性や事業・求人情報を自動照合する機能ではありません。ゲーム内では「AI未確認の候補・架空の職務」として示し、提案を確認済みの企業資料へ昇格させません。AIから `facts`・出典URL・報酬・確率・任意の更新は受け付けません。正確な事業資料を使う場合は既存の企業調査・確認の経路を使います。会社名やintentを追加しただけで独自の給与係数を作ることはなく、数値と成否は従来の検証済みの行動計算に従います。

Ollamaには行動ごとに必要な項目を必須化したJSON Schemaを渡します。返答は件数・行動・状態・資金・名前・長さ等を再検証し、JSONの項目が文章欄に漏れたものも拒否します。構造化された3つの転職案は同じswitchでも異なる企業として区別します。選択の意図、会社、役割、事業、地域は保存・再計算で保持し、巻き戻すとその分岐前に戻ります。

APIは `POST /api/scene` の `choiceVersion: 1` と `mode: "life" | "career"` でこの形式を使います。キャッシュにも種類・形式を含めます。旧クライアントの要求と過去の保存済み3〜5択は互換のため保持します。古いPCサーバーでは新形式を要求せず、次回起動までルールや手動交換で遊べます。実行中のサーバーや、メモリ内のAPIキーは自動で終了させません。クラウドは通常・転職とも送信同意後の手動生成のみ、自動再試行なし、既存の回数・費用上限を共有します。

## 検証

`npm run check` で、背景の違いの伝達、固定候補への限定がないこと、4択の強制、任意企業の選択・残留、学習・家族の文脈、移転先と起業の実行、保存・再計算、不正な証拠・報酬・重複・未来企業・形式の拒否、HTTP契約とホスト用の上限を確認します。有料通信は合成のテスト実装です。

M5・32GB、既存のOllama Gemma4 12Bを読み込み済みの状態で、合成人物を使った次の単発生成を確認しました。旧プロンプトの不正な返答を調整した後の結果で、継続的な成功率や予測精度の測定ではありません。

| 合成プロフィール                       | 種類 |   時間 | 受理した4択の例（職務は架空、企業情報未確認）                              |
| -------------------------------------- | ---- | -----: | -------------------------------------------------------------------------- |
| 自社SaaSのバックエンド・利用者調査     | 転職 | 33.1秒 | 残留・メルカリ・リクルート・ソニー銀行                                     |
| 受託/SI、AWS基盤・顧客折衝             | 転職 | 29.1秒 | 残留・野村総合研究所・楽天グループ・ソニーネットワークコミュニケーションズ |

今回の実機生成はローカルのみ。新しい4択のOpenAI実接続は未確認です。スマホのホスト用APIキー設定・Worker配備は引き続き未完了で、静的スマホ版では手動交換を使えます。
