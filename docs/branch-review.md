# 人生の分岐点の振り返り

記録された成功・不成立を、記録確率の低い順に最大3件選び、年代順に表示する。分岐直前まで元の seed、選択、保存場面、各ルールの適用境界で再生する。当時の選択肢について `choiceForecast` で初年度の成功率を再計算する。構成が未確定または実行不能な選択肢は計算対象外。旧セーブや場面がない場合も記録を表示できる。

比較は実際の選択と別の選択肢それぞれを分岐年に実行し、続く4年を「休む」で進める。元の履歴の続きや後続AI場面を使わず、同じ seed と年ごとの乱数チャンネルを使う。5年完了できない経路は除外する。純資産・年収の差の絶対値の最大が最も大きい別の選択肢を1件表示し、どちらも50万円未満なら大差なしとする。実際の最終値ではなく、条件を揃えた仮定の推定である。保存や元のゲームは変更せず、新たなAI呼び出しも行わない。


結末から各分岐点または決定のある年へ戻れる。確認画面から現在のセーブを任意で書き出せる。対象年の保存場面とそれ以前の記録を保ち、以後を破棄して同じseedとルール境界で再生する。保存場面がない年は場面の生成が必要になる。巻き戻し時のAI呼び出しは行わない。端末への保存を有効にしている場合は通常の進行と同じく保存が更新されるため、確認画面で先に書き出すよう案内する（レビューで確認）。
