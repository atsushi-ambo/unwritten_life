# 方針から次の決断への振り返り

入口は「まだ知らない、自分のつづきへ。」とし、別の選択をした自分の物語を体験する期待を伝える。キャリアと人生のシミュレーションゲームであることは、その下の説明に置く。現職での仕事・学び・転職・起業と、その先の仕事や暮らしを扱う。

年表の表示は新しい年から順に上へ追加する。履歴の保存順は変えない。振り返りと次の場面・四択は年表より上に配置し、長い年表を通り抜けずに次へ進める。過去の方針の記録は最新の記録の下に折りたたむ。スクロールや入力・詳細の展開で自動追従を止め、時間では再開しない。「最新の年へ戻る」、完了後は「次の選択へ戻る」で再開できる。入力中や読み返し中のカードは再作成せず、上への追加前後で位置を補正する。ゲーム表示中のブラウザのスクロールアンカーを無効にし、Safariも同じ補正を使う。

計算・確率・セーブの項目は変更しない。新たなAI呼び出しも行わない。年表をすべて表示した後、最後の完了した方針の期間に起きた変化を、次の場面の前に表示する。年収とゆとりの変化を短く示し、方針・純資産の差・転機は折りたたむ。景気や偶然も含む期間全体の変化であることは常時示す。

期間は保存済みの `directionBlocks` の末尾が履歴・決定数と一致するときだけ採用する。区切りがない旧セーブや途中への巻き戻しでは推測せず非表示。次の新しい方針から利用できる。方針の初年を含め、最大5年でも途中停止した実際の年数を使う。比較の始点は直前の年の記録、最初の方針だけは既存の `branchState(game, 0)` による初期状態。これは各ルールの適用境界を引き継ぎ、ゼロ年で再生する処理で、初期の住宅・借入などを含む純資産をプロフィールの預貯金と取り違えない。指標の記録が欠けていれば0とみなさない。

転機はキャリア終了、事業失敗・撤退・再就職、家族、その他のできごとの順で最大2件を選び、表示は年代順。同じ区間の再描画では表示を作り直さず、開いた詳細とフォーカスを保つ。途中の年月を見ている間は比較の数値を先出ししない。最後の年の表示後は、入力中や過去を読み返している場合を除いて振り返りへ案内する。

Claude Codeで設計と実装をそれぞれ独立レビューした。比較の始点・実際の年数・欠損・注意書きの常時表示・再描画時の詳細維持を採用した。決定数と履歴数はともに年単位なので、その点の懸念の説明は現行実装とは異なるが、旧記録の方針を推測しない方針は採用した。初期純資産はプロフィールの預貯金だけから計算すると住宅・ローンを落とすため、既存の初期状態の再生を維持した。

GitHubの恒久的な `pull_request_creation_policy=collaborators_only` をREST/GraphQLで確認済み。一時的な交流制限で代用していない。Issueは無効、共同管理者は所有者だけ。外部の報告受付は追加していない。Public化とライセンスの決定は別で、ライセンスは未設定のまま。
