# 選択から、次のできごとへ

> 2026-10-19追記：このゲームはAIの接続を必須にしました。毎年の場面・4択・転職候補はすべて接続したAIが本人の入力から作り、ルールで用意した選択肢と手動のJSON交換は使いません。新しい候補に固定の企業リストは使わず、旧セーブの再現用データだけを残します。接続先（ローカル・サブスクCLI・API）はどれでも毎年自動で生成し、クラウドは接続時の送信同意が必要です。一度提示・在籍した企業はセーブの `careerSeen` と `pastCandidates` でAIに渡し、繰り返さないよう指示します。過去の生成例・測定結果は記載当時の記録です。


参考にした [80億分の1](https://1in8b.life/ja/) の操作を確認し、日々の記録が積み重なり、節目で選択する流れを着想として採用した。文章・画像・統計データ・コードはコピーしていない。

PC版の画面はステータス、コマンド、年次結果をRPGのウィンドウとしてそろえる。コマンドは通常のTab操作に加え、↑↓・Home・Endで移動、Enterで決定できる。外部フォント・画像は使わない。

同作の年ごとのマップ・節目の問い・記録の振り返りも仕組みの着想とし、このゲームではキャリアの履歴から独自に組み立てる。1マスは過ごした1年。退職、転職、学び、休養・ケア・求職、事業、仕事の順に主な活動を分類し、色と記号で示す。マップは保存せず履歴から再計算する。在籍期間とは別の分類なので、学びや休養の年も職場の期間には含まれる。

プレイ中に30・40・50・60歳へ到達した年と退職の節目では、年次結果の後に一行を任意入力できる。最大5年・10年の進行もここで止める。同年の退職と年齢の節目は一つにまとめ、開始時や旧セーブの過去の節目をまとめて質問しない。80文字・一行の記録と空欄での通過をセーブの任意項目 `reflections` に残す。旧セーブは空の記録として読み込める。巻き戻して未到達になる記録は取り除く。AIの文脈にも生成リクエストのセーブにも一行を含めない。

終了時の「わたしの履歴書」は、この世界の勤務先・役割の期間、主な活動の年数、転機、一行、マップを履歴からまとめる。テキストを端末のクリップボードにコピーでき、コピーが使えない場合は選択用テキストを表示する。外部への投稿や画像共有は行わない。キャリアログの☆と「お気に入りだけ」はメモリ内の機能。再開・読み込み・新しいゲームでリセットし、巻き戻した年の印も外す。

## 入力の3段階

- すぐ始める：プリセット・関心・物語の雰囲気を選ぶだけ。詳細欄の見出しも非表示にし、開始ボタンは一つにする。
- 詳しく：プリセットを隠し、年齢、エリア、市区町村、30種類の職種、業界、仕事内容、会社名、仕事の形、AIとの距離、希望、年収を任意入力。職歴メモは任意の折りたたみ欄にする。
- さらに詳しく：詳しくの項目に住まい、資産内訳、ローン、生活費、退職後収入、家族を追加する。すべて任意。

非表示の入力はdisabledにし、新規ゲームの正規化でも段階別の許可項目だけを選ぶ。詳細から簡単へ戻っても古い会社・市区町村・家計はプリセットに混ざらず、詳細に戻すと入力途中の値を再利用できる。

学生・求職/休職等が中心なら勤務先・業界を隠す。自営・フリーランスでは仕事の形と会社規模を重ねて選ばせず、自営として扱う。会社情報は会社名があるときだけ確認欄を表示し、検索後に開く。子どもの年代は人数が1以上のとき、家賃は賃貸等のとき、不動産とローン残高は持ち家のとき、返済期間と金利はローン残高が正のときだけ表示する。

市区町村は80文字まで、番地や位置情報は求めない。地名を物語に使い、家計は既存の3区分と手入力金額を使う。地名から家賃・給与・求人を推定しない。ゲーム内の移動後は元の市区町村名を現在地として使わない。具体職種は既存の広い仕事区分へ対応づけ、17種類の業界・120文字までの仕事内容は能力や給与の加点には使わない。AIには開始時の本人入力として渡し、転職後の現職の情報と区別する。

フォームの空欄は `optionalProfileInputs` で、選んだプリセットか明示したゲーム用の仮値に置き換える。明示した0円は0円のまま。任意入力であっても値の範囲・内訳は従来の `validateProfile` で検証する。セーブの取込にはフォーム用の空欄変換を使わない。保存オフで新しいゲームを始めても、以前の任意保存を自動削除しない。

## 毎年の物語と複数年進行

語りの軸はキャリアの歩み。仕事・学び・残留や転職・小さな試み・起業と、家族・家計・住まい・AIで変わる労働市場を結びつける。年ごとの画面と履歴はキャリアと暮らしの記録として読み、結末では働いた年月が残した経験やつながりを振り返る。新規ゲームは仕事を終えた年に完結し、「わたしの履歴書」を表示する。以前のセーブで記録済みの退職後の年は保つ。転職を強制せず、通常の4択は休養や家族なども含める。

`advanceYears` は従来の `advance` を一年ずつ実行し、各年の計算済みの結果を残す。繰り返せるのは学習、現在の仕事、休養、人との時間などの方針。転職・起業・家の購入・移動・ローンの繰り上げ返済・家族を迎える準備などはまず一年だけ実行する。家族の変化、退職、事業終了、人生の完結では途中でも止まる。5年・10年は最大の年数で、結果を先に固定する約束ではない。

各年の結果と直前の振り返りには「家計の内訳」を表示し、履歴では折りたたんで確認できる。現金の収支を符号付きで示し、資産の評価損益は別記する。旧履歴に内訳がなくても本文は表示する。

`annualEpisode` は行動、実際の評価・失敗、仕事の形、学びの継続、家族、世界の局面から短い架空の文章を組み立てる。新しい金額・採用・家族を文章だけで確定させない。数値の計算・乱数・世界の係数は変更しない。出来事の画面→次の年の場面→次の選択、と進め、記録や直前の振返りでも読める。

日常の小さな寄り道も、年・人生の乱数・家族や働き方から選ぶ。勉強会が気になれば人と会う案、別の街が気になれば暮らす場所を考える案へつなげ、実行可能な場合だけ次の4択に出す。寄り道の文章だけで数値を加点したり、採用や家族を確定したりしない。

この短い年次記録は端末内のルールによる生成で、LLM生成と表示を分ける。接続したAIが次の4択を作るときには、直近の出来事も参考に渡す。PCの自動生成は記録を読み終えた後に一度呼び出し、複数年の全年度へ自動で有料APIを呼ばない。スマホ版もOpenAIで毎年自動生成し、手動JSON交換は使わない。累計2000回または見積り$5で停止する。

## 会社名からの取得

会社名の横に取得ボタンを置く。企業の概要は内蔵せず、固定のWikidata APIの会社候補・説明・公式サイト項目を使う。同名候補は本人が選ぶ。スマホでは外部会社の公式ページ本文は取得せず、ディレクトリの説明であることを表示する。PCのURL指定による公式本文取得は従来の制限付き経路を維持する。

ブラウザから送るのは企業名と検索用の公開候補IDだけで、プロフィール全体や年収・資産・職歴は送らない。匿名CORS、認証情報なし、リダイレクト拒否、10秒、512KB。任意のURLやJSONPは取得せず、CSPも固定APIだけを許可する。[MediaWikiの公式CORS仕様](https://www.mediawiki.org/wiki/API:Cross-site_requests)を使用。企業情報を本人が確認するまでは、数値へ確認済みの事業情報として反映しない。

## 検証

`npm run check` で、空欄と0の区別、入力範囲の拒否、5年分の記録と復元、節目での停止、仕事の形による文章の違い、3段階のフォーム、検索の固定通信先・認証情報なし・サイズ制限を確認する。実ブラウザでの会社検索や画面遷移は、単体テストと別に確認する。
