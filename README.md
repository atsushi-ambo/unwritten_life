# Unwritten Life

**自分のままで、いくつもの未来を。**

2026年の自分から、生涯の選択を体験するローカルの人生ゲームです。仕事、資産、住まい、家族や人との時間が、その後の収支と場面を変えます。AIは利用者が選んで接続でき、接続しなくても遊べます。

## 遊ぶ

Node.js 24 LTS を推奨。24〜26に対応します。

```sh
cd /Users/atsushiambo/personal/app/unwritten_life
npm ci --ignore-scripts
npm run play
```

macOSでは **`start.command` をダブルクリック**でも起動できます。ゲームと必要なOllamaをPC内で起動し、ブラウザを開きます。終えるときは起動したターミナルで `Ctrl+C`。他の作業用にすでに起動していたOllamaは終了させません。

AIを使わずに開発用サーバーだけ動かす場合は `npm run dev`。URLは <http://127.0.0.1:4317>。別ポートは `PORT=4318 npm run play`。

## ローカルAIを使う

最初に [Ollama](https://docs.ollama.com/quickstart) をインストールし、モデルを取得します。

```sh
ollama pull qwen3:8b
```

モデルは約5.2GBです。モデルの重みはリポジトリには含めません。初回のインストール・モデル取得にはインターネット接続が必要ですが、このローカルモデルによる生成にAPI料金はかかりません。モデルは利用者の環境に置かれ、ライセンスは各モデルの条件に従います。

ゲーム内の **「この場面をAIで生成」** を押すと、年齢、仕事、会社の情報、現在の家計、住まい、過去4年の選択、AIの普及シナリオから場面を生成します。初回はモデル読み込みにも時間がかかります。自動リトライや毎年の自動呼び出しはしません。1年・5年・10年で進められ、複数年の途中はルールで処理します。

ランチャーがOllamaを起動する場合は `OLLAMA_NO_CLOUD=1`、`127.0.0.1:11434` に限定します。すでに利用者が起動しているAIサーバーの設定は変更しません。

## 好きなAIに切り替える

画面上部の「AIの接続」から選べます。

| 接続先 | 方式 | この版での対応 |
| --- | --- | --- |
| Ollama | ネイティブ `/api/chat` | ローカル生成。初期モデル `qwen3:8b` |
| LM Studio | OpenAI互換API | `http://127.0.0.1:1234/v1`。実際のモデルIDを指定 |
| OpenAI | Chat Completions API | 自分のAPIキー・モデル・単価を設定 |
| OpenRouter | OpenAI互換API | 自分のキー・モデルを指定。無料モデルも利用者が選択 |
| その他 | OpenAI互換API | ベースURLとモデルを指定。ループバックまたはHTTPSの公開先 |
| ChatGPT / OpenCode / 任意のAI | 手動交換 | 生成用の文章をコピーし、返答のJSONを取り込む |

ChatGPTやOpenCodeの自動操作、OpenCode独自のサーバーAPI、ChatGPTのOAuthログインはこの版では実装していません。手動交換で利用できます。[Sign in with ChatGPTの公式OSS向けガイド](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)は、将来の接続方式の候補です。

クラウドへ送る前に送信先と内容を画面で確認し、送信への同意を選びます。APIキーはローカルサーバーのメモリにのみ保持し、端末保存・Git・レスポンス・ログには含めません。アプリを終了すると失われます。

費用は [docs/ai-and-costs.md](docs/ai-and-costs.md) を参照。設定単価からの見積り上限、回数上限、1回の出力上限、同じ場面のキャッシュを設けています。提供者の実請求を保証する上限ではありません。

## 入力と、選択で変わること

基本は8項目。金融資産は合計だけでも始められます。任意で株式・投信の内訳、不動産の評価額、住宅ローン残高・金利・期間、生活費、家賃、退職年齢、65歳以降の収入、勤務先と公開資料を設定します。金融資産の内訳は合計と二重計上せず、不動産と住宅ローンは別枠です。

学び、仕事、人との時間、休養、挑戦に加え、条件に応じて転職、資産配分、住居購入、地域変更、退職を選べます。選択は将来の収入、支出、資産構成、スキル、ゆとり、関係と次の場面に反映します。退職後も進み、ゲーム内の最期を迎えると振り返りが表示されます。

会社情報は「会社名をGoogleで検索」→「公式ページのURLを指定して取得」→内容と会社の一致を確認、という流れ。ページ取得でLLMや有料検索APIは使いません。取得した本文は未確認の資料で、現在の公開情報と架空の未来を区別します。会社名だけから業績や個人の将来年収を作り上げる処理はありません。

## 保存とプライバシー

端末保存は初期状態でオフ。オンにするとプロフィール・選択・生成した場面をlocalStorageに保存します。同じブラウザを使う人から読める可能性があり、暗号化された保管庫ではありません。APIキーは含めません。「保存を削除」で消去できます。

旧20年版（v1）のセーブを新モデルで黙って上書きしません。旧データがある場合は保持し、ローカルファイルへ書き出せます。v2では新しい物語から始めてください。

## 検証

```sh
npm run check
npm run audit
```

ローカルとCIで同じ入口を使います。計算、全職種・3世界での生涯終了、転職・住まい・資産配分、退職、保存復元、巻き戻し、モデル出力の拒否、実HTTPのAI接続、CSRF・Host・パス・SSRF・容量上限を合成データで検証します。CIはNode 24/26でPR・mainへのpush・手動・週次に実行。外部ActionsはSHA固定、依存はlockfile固定です。クラウドの有料APIをCIから呼びません。

## モデルの限界と公開状態

個人の寿命・病気・収入・投資リターンを予測するモデルではありません。AIを追加しても、その予測精度が検証されたことにはなりません。ゲームとしての計算と、入力に合う物語の生成を分けています。係数・会計・死亡判定・比較の限界は [docs/design.md](docs/design.md) に記載しています。

リポジトリは現在非公開。将来、利用者が自分でインストールしAIを選べるOSSとして公開することを想定しています。ライセンスの確定と一般公開はまだ行っていません。
