# Unwritten Life

**その転職の、ずっと先の未来まで。**

2026年の自分の職歴から、転職・学び直し・起業などのキャリアの選択を生涯にわたって体験する、キャリアと人生のシミュレーションゲームです。仕事、資産、住まい、家族や人との時間が、その後の収支と場面を変えます。

**遊ぶにはAIの接続が必要です。** 5年ごとの場面と4つの方針、転職先の候補は、あなたの入力から接続したAIがゼロから作ります。新しい候補に固定の企業リストや、ルールで用意した選択肢は使いません（旧セーブの再現用データは残します）。どのAIを使うかは自由です（PC内のOllama・LM Studio、ChatGPT/Claudeのサブスク（Codex CLI・Claude Code）、OpenAI・OpenRouterなどのAPI）。

## 遊ぶ

Node.js 24 LTS を推奨。24〜26に対応します。

```sh
git clone https://github.com/atsushi-ambo/unwritten_life.git
cd unwritten_life
npm ci --ignore-scripts
npm run play
```

macOSでは **`start.command` をダブルクリック**でも起動できます。ゲームと必要なOllamaをPC内で起動し、ブラウザを開きます。終えるときは起動したターミナルで `Ctrl+C`。他の作業用にすでに起動していたOllamaは終了させません。

開発用サーバーだけ動かす場合は `npm run dev`。URLは <http://127.0.0.1:4341>。別ポートは `PORT=4342 npm run play`。

ほかのアプリと同じ `make` の入口も使えます（2026-10-20追加）。中身は上の `npm` コマンドと同じです。

| コマンド | 内容 |
| --- | --- |
| `make dev` | ゲームを起動してブラウザを開く（`npm run play`） |
| `make stop` | 起動中のゲームを止める。ポートを別のアプリが使っている場合は止めない |
| `make check` | 構文・単体テスト・依存関係の脆弱性検査 |
| `make e2e` | ブラウザのテスト（Playwright） |
| `make help` | コマンドの一覧 |

既定のポートは2026-10-20に4317から4341へ変えました（4317はOpenTelemetryの標準ポートと重なるため）。別ポートは `make dev PORT=4342`。

初めて開くと、画面上部と開始欄に「AIを接続する」が表示されます。PC内（ローカル）・サブスク（CLI）・API（従量課金）を選び、接続先・モデルを選択します。短いJSONを実際に生成して成功すると始められます（2026-10-19更新）。確認中は待ち時間を表示し、失敗時は理由を表示します。PC内のAIとサブスクCLIは、このブラウザに接続先（とクラウドへの送信同意）を記憶し、再読み込みでも生成を確認してつなぎ直します。APIキーは保存しないため、API接続はサーバー起動ごとに入力します。接続確認はゲームの回数に含めず、APIではUSD見積りを予約します。APIは初期100回・最大300回／見積り$1、ローカルは初期1000回・最大5000回／USD上限なしです。

2026-10-19追記：起動中にサーバーのソースが更新されると、開始を止めて再起動を案内します。古いサーバーが残っている場合は、ターミナルでCtrl+Cで止めてから `start.command`（`npm run play`）を実行してください。

## スマホ版（本人専用）

スマホ版は、所有者本人のOpenAIアカウントで動く[本人限定のWorker版](hosted/README.md)です。5年ごとの場面と方針をOpenAIで自動生成し、見積り累計$5で停止します。

「セーブを書き出す」で保存したJSONファイルを、別の端末の「セーブを読み込む」で選ぶと、PC版とスマホ版の間で続きを移せます。端末内に保存するのは「この端末に物語を保存する」がオンの場合だけです。

`npm run build:mobile` で、配信用のHTML・CSS・ブラウザのゲーム処理だけを `artifacts/mobile/` に出力します。出力先を変える場合は `npm run build:mobile -- --output 出力先`。APIキー・実際のセーブは含みません。新しい場面の生成にはWorkerのAI APIが必要で、静的ファイルだけでは遊べません。会社検索は企業名だけを固定のWikidata APIへ送り、会社概要と公式サイト候補を取得します。未取得の公式本文を取得済みと表示しません。PCのセーブとは自動同期しません。

## ローカルAIを使う

最初に [Ollama](https://docs.ollama.com/quickstart) をインストールし、モデルを取得します。

```sh
ollama pull qwen3:8b
```

モデルは約5.2GBです。モデルの重みはリポジトリには含めません。初回のインストール・モデル取得にはインターネット接続が必要ですが、このローカルモデルによる生成にAPI料金はかかりません。モデルは利用者の環境に置かれ、ライセンスは各モデルの条件に従います。

Apple M5・メモリ32GBで、このゲームの文章と待ち時間のバランスを取るなら **Gemma 4 12Bの4bit版** を推奨します。取得後、ゲームの「AIの接続」→Ollamaの一覧で `gemma4:12b-it-q4_K_M` を選びます。

```sh
ollama pull gemma4:12b-it-q4_K_M
```

約8GBのモデルです。このPCの最新の個人向け4択で5場面を生成し、中央値41秒でした（旧プロンプトでは31秒）。生成内容には補正や誤りも残り、全モデルの総合順位ではありません。[比較結果・限界・再実行方法](docs/local-models.md) を参照してください。

Ollama・LM Studioでは、ダウンロード済みモデルの一覧から選べます。どの接続先でも、開始時と5年の方針を選んだ後に、次の場面を自動生成します。年齢、仕事、会社の情報、現在の家計、住まい、前回の決断からの年ごとの記録、AIの普及シナリオを使います。初回はモデル読み込みにも時間がかかります。1回ごとに結果と家計の変化を先に示し、そこから次の場面と4個の選択肢をAIで作ります。自動リトライはせず、失敗したときはその年で止まり、「もう一度生成する」か接続の変更を選べます（2026-10-20：PC内のAIで、返答がゲームの条件を満たさなかったときだけ1回自動で作り直します。費用がかからないためです。通信エラー・時間切れ・クラウドのAIでは自動で作り直しません）。ルールで作った選択肢に切り替わることはありません。方針は5年単位で選び、年ごとの表示中に次のAI生成を進めます。クラウドのAIは、接続時に送信内容へ同意したときだけ使えます。

ランチャーがOllamaを起動する場合は `OLLAMA_NO_CLOUD=1`、`127.0.0.1:11434` に限定します。すでに利用者が起動しているAIサーバーの設定は変更しません。

## 好きなAIに切り替える

画面上部の「AIの接続」から選べます。

| 接続先                        | 方式                   | この版での対応                                           |
| ----------------------------- | ---------------------- | -------------------------------------------------------- |
| Ollama                        | ネイティブ `/api/chat` | ローカル生成。初期モデル `qwen3:8b`                      |
| LM Studio                     | OpenAI互換API          | `http://127.0.0.1:1234/v1`。実際のモデルIDを指定         |
| OpenAI                        | Chat Completions API   | 自分のAPIキー・モデル・単価を設定                        |
| OpenRouter                    | OpenAI互換API          | 自分のキー・モデルを指定。無料モデルも利用者が選択       |
| その他                        | OpenAI互換API          | ベースURLとモデルを指定。ループバックまたはHTTPSの公開先 |
| Codex CLI / Claude Code       | 公式CLI                | ChatGPT・Claudeのサブスクのログインを使う                |

PC版のAI設定で **Codex CLI / Claude Code** を選ぶと、公式CLIのサブスクログインで5年ごとの場面を生成します。APIキーは使わず、契約の利用枠（5時間枠など）を使います。暴走防止として起動中1000回（最大5000回）・同時1件・生成1回120秒までに制限します。Claude CodeはHaiku・Sonnet・Opus（初期Sonnet）、CodexはローカルCLIで確認したモデルの一覧から選びます（初期gpt-6.1-sol）。利用上限は専用の案内で止め、自動再試行しません。普段のCLIと利用枠を共有します。各社の追加利用・自動購入設定はアプリから変更できないため、契約側で無効にしてください。[設定と検証結果](docs/subscription-ai.md) にまとめています。スマホからPCのCLIは呼び出しません。

クラウドのAI（API・サブスクCLI）は、接続時に送信内容（年齢・家計・勤務先・家族・選択履歴）への同意が必要です。送る情報は「AIに渡す情報を確認」で見られます。PC版のAPIキーはローカルサーバーのメモリにのみ保持し、端末保存・Git・レスポンス・ログには含めません。アプリを終了すると失われます。スマホ版は[サーバーの秘密情報と累計上限を使うOpenAI接続](hosted/README.md)で、累計2000回または見積り$5で停止します。

費用は [docs/ai-and-costs.md](docs/ai-and-costs.md) を参照。設定単価からの見積り上限、回数上限、1回の出力上限、同じ場面のキャッシュを設けています。提供者の実請求を保証する上限ではありません。

## 入力と、選択で変わること

2026-10-20更新：開始画面は「すぐ始める」「詳しく」「さらに詳しく」の3段階。「すぐ始める」では年代（新卒22歳・20〜60代）と地域（大都市圏・地方の中心都市・地方の市町村）を選び、年収・資産・生活費・家賃にゲーム用の目安を使います。初期値は新卒・地方の中心都市、家族の設定は中立です。「詳しく」では年代・地域の簡単選択を隠して年齢・市区町村・30種類の職種・業界・仕事内容・会社・年収を任意入力します。「さらに詳しく」で家族・住居・金融資産・ローンを追加。子どもがいる場合だけ年代、持ち家でローンがある場合だけ返済条件を表示します。切り替えても入力途中の内容は残し、選んだ段階の項目だけで開始します。市区町村名は物語に使い、地域の相場を調べた情報とは扱いません。空欄の金額はゼロと混同せず、表示した仮値を使用します。会社名の横の「会社情報を取得」から調べ、取得元を確認して使えます。

「気になる会社・仕事」は任意のAI向けヒントです。候補をこの入力に限定せず、能力や採用の根拠にも使いません。

PC版・スマホ版の両方で、職歴メモのテーマ、確認した勤務先の事業、現在の家族と希望、住まい・ローン、手元資金を、場面と4択の理由へ組み込みます。「この場面に反映したプロフィール」から使った入力を確認できます。端末内ではキーワードと条件による生成で、未知の自由文はメモとして引用します。全文の解釈は接続したAIに任せます。学習などを複数年続ける場合は選んだテーマと意図を引き継ぎ、メモの長さや専門語で能力を加点しません。[プロフィールと物語の対応・検証](docs/profile-story.md)。

会社検索は候補が1件でも「この会社で合っていますか？」で確認します。企業の資料は内蔵せず、毎回Wikidataの候補から選び、公式サイトの本文（スマホ版はWikidataの概要）を取得します。選ぶと会社名は選んだ正式名称へ変わり、取得した内容は確認のチェック後に物語へ反映します。名前や本文の変更で確認を解除し、検索・取得途中の古い結果も適用しません。外部検索が空の場合は法人表記を除いて一度だけ再検索します。未知の会社や大きな入力違いは見つからない場合があり、URLや会社情報を推測して補いません。

2026-10-20更新：方針は5年ごとに選び、各年の結果を同じ画面のタイムラインへ順に表示します。転職・購入・移動などは初年だけ行い、その後は仕事や学びなどを続けます。家族の変化・退職・事業の終了・重い出来事では早めに選び直します。30・40・50・60歳と退職の一行は任意で、書かなくても進みます。一時停止・再開、等速（1年約6秒）・2倍（約3秒）、残りをまとめて表示する操作が使えます。Undoは最後の方針の全年度を戻し、境界のない旧セーブは1年戻します。転職4択の比較画面は残っています。

22〜65歳は通常約9回の決断で、通しプレイの目安は15〜20分です。年の表示だけなら43年×6秒で約4分半。残りは各場面を読み方針を考える時間（1回1〜2分程度）を想定し、AI生成は年の表示と重ねます。早期の選び直しやAIの待ち時間で変わり、所要時間を保証するものではありません。

キャリアを主軸に、日本の景気・架空の勤務先の業況・国際紛争や災害の局面が収入・資産・支出を変えます。世界の局面は原則3年継続。AIの能力と現場での普及は別の曲線です。「1日1時間の学び」は年間365時間とスキルを蓄積し、後の評価の確率を上げますが、努力しても評価されない年、成功しても景気で収入が下がる年があります。

**思いがけない出来事**も起きます。良さそうな会社に転職したのに上司と合わない、ハラスメントで休職する、勤務先の人員整理やパートナーの失職、親の介護、信頼できる仲間や大きな役割に恵まれる、などです。起きるかどうか・種類・重さはゲームがseed付きの乱数で決め（1年に最大1件、何か起きる年は約3割）、誰がどんな状況で、という具体はAIが本人の職場や家族に合わせて描きます。結果欄にはその確率を「ゲームの仮定」として表示し、重い出来事のあとは4択に向き合い方の案が入ります。[出来事の一覧と確率](docs/probability-model.md#思いがけない出来事2026-10-19)。

家族の希望は結果の保証ではありません。新しい出会い、家族を迎える準備、家族を支える働き方、希望人数に達した後でもうひとりを考える分岐を用意しています。新しい家族は準備の行動後の抽選で迎え、希望の見直しだけで自動的に増やしません。現在の家族の生活費は初期設定、新しく迎えた子の費用だけを追加する簡略モデルです。

結果欄で、行動の成果・学習時間・家計の変化と世界からの影響を確認できます。確率と状態の計算はゲーム側、年ごとの場面と提案の表現はAI側。歴史的な普及データは参考資料としてアプリに内蔵し、将来の確率は実測から推計したものではありません。[確率・技術普及の設計と出典](docs/probability-model.md) を参照してください。

歴史・技術普及8件、ゲーム独自の前提9件を、**端末内の知識DB（IndexedDB）**に保存します。企業の資料は内蔵しません。本人の仕事の形・家族・住居・直前の行動から関連資料をローカルで検索し、AIへは歴史最大2件・前提最大4件だけを渡します。学習の次は学びと評価、子育て中は家族の負担、転職後は新しい仕事の形に応じて参照内容が変わります。参照資料と出典は「この世界の仕組みと、端末内の知識」で確認できます。

ここでの知識の蓄積は、確認した資料を再利用する仕組みです。モデルの追加学習は行いません。プロフィール・セーブ・選択履歴・AI生成文は知識DBに混ぜません。PCとスマホのDBはそれぞれのブラウザ内にあり、自動同期しません。ブラウザによるデータ削除や保存拒否があっても、同梱の資料で続けられます。AIが挙げた企業を自動で事実として登録しません。[知識DBの構成・更新方法](docs/local-knowledge.md)。

LinkedInの職歴自動取得は未対応です。一般的なログインで職歴全体を取得できるとは限らず、公式APIの利用条件を確認する必要があります。当面は任意の職歴メモを物語へ反映します。

基本は8項目。金融資産は合計だけでも始められます。任意で株式・投信の内訳、不動産の評価額、住宅ローン残高・金利・期間、生活費、家賃、退職年齢、65歳以降の収入、勤務先と公開資料を設定します。金融資産の内訳は合計と二重計上せず、不動産と住宅ローンは別枠です。

学び、仕事、人との時間、休養、挑戦に加え、条件に応じて転職、起業、資産配分、住居購入、地域変更、退職を選べます。選択は将来の収入、支出、資産構成、スキル、ゆとり、関係と次の場面に反映します。成果・不調・起業の失敗なども起こり、学びの実証、成果を使った待遇の相談、事業拡大、方向転換、撤退、生活の立て直しが結果に応じて現れます。新規ゲームでは、設定した退職年齢に達した時点で、転職・起業などの就業中の選択肢は表示しません。旧セーブは保存中の場面まで旧ルールを保ちます。物語はキャリアの区切りで完結します。定年を迎えた年、自分で仕事から離れた年に終わり、部長級・上級専門職なら「退任」、起業していれば「事業から退く」として締めくくります（以前のセーブは、記録済みの退職後の年もそのまま続きます）。最後には **わたしの履歴書** が表示され、年収（はじめ→ピーク）・純資産（はじめ→おわり）・いちばん上の役職・転職の回数と勤めた会社の数・家族・住まい・学びの時間・思いがけない出来事の数と、年代ごとの転機（転職、昇格、社内異動、家族、家の購入、つらい出来事とうれしい出来事）を一覧にします。テキストとしてコピーもできます。

**今の会社に残ってキャリアを築く道**も、転職と同じ重みで選べます。会社員として働いている年は、AIの4択に必ず1つ以上「今の会社で次の一歩を踏み出す」案が入ります（昇進・昇格を目指す、社内異動に手を挙げる、社内の新規事業・公募に応募する、今の仕事を深める、AI活用を試す、待遇を相談する、後進を育てる）。生成された4択にこの案がなければ採用せず、その年で止まります。「もう一度生成する」から再生成できます。役職は「担当 → リーダー → 管理職か専門職 → 部長級か上級専門職」というゲーム内の一般的な段階で、実際の会社の等級や人事制度を作ることはありません。昇格できるのは一部の人だけです。実力（スキル・ゆとり・今の段階での年数）に加えて、上の席が空くかどうかの運が必要で、席は上ほど少なく、勤務先が伸びているときは空きやすく、逆風のときは空きにくくなります。前の年に良い上司や大きな役割に恵まれると昇格しやすく、上司と合わなかった年のあとは通りにくくなります。2年ごとに昇格を狙い続けた合成プレイの30年では、リーダーにはほぼ全員が届きますが、管理職は約半数、部長級は約5%です。たまにしか狙わない場合は管理職が約4分の1、部長級は約1%で、多くの人はリーダーや管理職・専門職の段階で長く働きます。他社へ一つ上の段階（管理職や部長級など）で転職する道もありますが、慣れるまでは難しく、成功は保証されません。開始時の立場は「詳しく」で選べます。同じ会社での役職や部署の変化は、キャリアマップと職務経歴書に載ります。転職すると、それまでの段階は引き継ぎ、部署と在籍年数は新しい会社で数え直します。

**転職・残るの4択**では、AIが勤務先の仕事の形（自社サービス・受託/SI・社内ITなど）、専門・職歴、暮らし、直前の結果から企業・役割・接点を生成します。企業は固定リストを持たず、本人の入力から毎回考えます。近い仕事の形の企業、別の事業で経験を使う企業、意外な接点と残留を比較します。一度出た企業と在籍した企業はセーブに記録してAIへ渡し、次の比較では別の企業を考えるよう指示します。AI候補の企業・職務は未確認のゲーム内提案で、実際の求人・内定・給与ではありません。通常の学習・家族・起業・住居等も本人に沿う4択とし、具体的に選んだ意図を履歴へ残します。[設計・実機の生成例](docs/personalized-choices.md)を参照してください。

**起業**では、AI支援・創作スタジオ・地域生活支援・小さな農園から事業を選びます。名前は省略可能で、その年に現れる起業の誘いにも選択だけで進めます。開業費・毎年の運営費と収入の変動が家計に反映されます。転職・起業は初年だけ実行し、その後は通常の仕事や事業を続けます。巻き戻し・保存・別世界の比較でも選んだ会社や事業を再現します。費用や収入の係数・企業資料の扱いは [設計メモ](docs/design.md#会社と事業の分岐) に記載しています。

会社情報は、企業名を入れて **「企業名から公式情報を調べる」** を押すと公式サイト候補を探し、本文を取得します。候補にはWikidataの公式サイト項目を使います。送るのは企業名のみで、プロフィールや家計は検索先に送りません。同名の場合は企業の候補を選び、取得元と内容を確認します。見つからない・取得できない場合はURLの直接指定も使えます。ページ取得でLLMや有料検索APIは使いません。取得した本文は未確認の資料で、現在の公開情報と架空の未来を区別します。会社名だけから業績や個人の将来年収を作り上げる処理はありません。

各年の結果と履歴で、手取り収入・年金・生活費・住居費・ローン元金と利息などの現金収支を確認できます。ローンが残り、現金が生活費半年分を超えると、今年の支払いも確保できる範囲で繰り上げ返済を選べます。返済期間を維持して返済額を減らします。方針の初年だけ繰り上げ、その後の年は通常の返済を続けます。不足分の借入は毎年、生活費半年分を超える現金から自動返済し、残高に年2%の利息を加算します。年収は職種・地域・会社タイプ別の目安に近づくほど昇給幅が小さくなり、長期でも極端な複利成長にはなりません。2026-10-20からは目安を賃金統計に近い水準へ下げ、55歳前後を頂点に、会社員は60歳で再雇用として下がります。転職での年収の変化は平均して小さく、一つ上の役職での転職は今の役職で3年たってからです。

## 保存とプライバシー

端末保存は初期状態でオフ。オンにするとプロフィール・選択・生成した場面をlocalStorageに保存します。同じブラウザを使う人から読める可能性があり、暗号化された保管庫ではありません。APIキーは含めません。「保存を削除」で消去できます。

旧20年版（v1）のセーブを新モデルで黙って上書きしません。旧データがある場合は保持し、ローカルファイルへ書き出せます。v2では新しい物語から始めてください。以前のv2セーブは過去の計算を保ち、続きから新しい世界・家族モデルを使います。

## 検証

```sh
npm run check          # 単体・統合テスト
npm run audit          # 本体の本番依存
npm run audit:all      # 本体・スマホ版の全依存（例外なし）
npm run check:hosted   # 一時環境でスキーマ生成・Workerビルド・型検査
npx playwright install chromium webkit
npm run test:e2e       # PC幅・スマホ幅・スマホ版WebKitの実ブラウザ操作
# gitleaks 8.30.1 がPATH上に必要（macOS: brew install gitleaks）
npm run check:secrets  # Git履歴と現在のソース。値は伏せて出力
npm run check:release  # 上記検査を順に実行。失敗時はそこで停止
```

ローカルとCIで同じ入口を使います。計算、全職種・3世界での生涯終了、転職・住まい・資産配分、退職、保存復元、巻き戻し、モデル出力の拒否、実HTTPのAI接続、CSRF・Host・パス・SSRF・容量上限を合成データで検証します。CIはUbuntu 24.04・Node 24/26でPR・mainへのpush・手動・週次に実行。外部ActionsはSHA固定、依存はlockfile固定です。クラウドの有料APIをCIから呼びません。

2026-10-20追加：`automerge` ラベルを付けたPRは、CI（Check）が最新のコミットで全部成功すると自動でマージします（`.github/workflows/automerge.yml`）。GitHub本体の自動マージとブランチ保護は、無料プランの非公開リポジトリでは使えないための代わりです。対象はこのリポジトリのブランチから所有者が作った、下書きでない main 向けのPRだけです。PRのコードは実行しません。検査の後に新しいコミットが積まれていればマージしません。ラベルを外せば手動マージに戻せます。

CIにはスマホ版のWorkerビルド・型検査・未認証APIのHTTP拒否、全依存監査、PlaywrightによるPC/320px幅と、生成済みスマホ版を実際のWorker経路で配信した390px幅・iPhone相当のWebKitで、合成のAI返答（本物の検証を通した4択）を使った年の進行・転職4択・AI未接続時の接続案内・記録ダイアログ・巻き戻し・保存復元・保存削除・横はみ出し・外部通信なしの検証、Gitleaksによる履歴と現在のソースの検査を追加しています。Gitleaksは公式リリースのバージョンとSHA-256を固定し、合成トークンを検出できることも毎回確認します。実際のキー、保存データ、外部AIはテストに使いません。検査用の依存・生成物・ブラウザ結果は一時ディレクトリに隔離し、`artifacts/` と `.claude/` は対象外です。

スマホ版はSites対応の自己完結したWorker ESMへ整理しました。画面は既存のHTML/JavaScriptをそのまま配信し、共有バックエンドでAIの認証・同意・CSRF・利用上限を検証します。不要なNext/Vinextとlint用依存を取り除いたため、開発用を含む全依存監査は例外なしで0件です。新しい警告は重大度を問わずCIを失敗させます。[スマホ版の検証詳細](hosted/README.md)も参照してください。

配備は手動です。配備候補に `npm run check:release` と最新コミットのGitHub CI成功を要求し、Sitesの正式なビルド・配備手順を実施してから起動・主要操作を確認します。CI用の仮Site設定を配備に使わず、既存Siteの本人限定範囲とD1累計を維持します。現在のGitHubプランでは非公開リポジトリのブランチ保護を利用できないため、マージ前に対象コミットと全ジョブの成功を手動で照合します。自動配備、ブランチ保護の強制、スマホ実機での検証は整備済みと扱いません。

## モデルの限界と公開状態

個人の寿命・病気・収入・投資リターンを予測するモデルではありません。AIを追加しても、その予測精度が検証されたことにはなりません。ゲームとしての計算と、入力に合う物語の生成を分けています。係数・会計・死亡判定・比較の限界は [docs/design.md](docs/design.md) に記載しています。

リポジトリは現在非公開。将来、利用者が自分でインストールしAIを選べるOSSとして公開することを想定しています。ライセンスの確定と一般公開はまだ行っていません。
